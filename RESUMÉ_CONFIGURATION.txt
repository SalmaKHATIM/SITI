VOS QUESTIONS RÉPONDUES:
═══════════════════════

Q1: Comment connecter l'app avec la base de données?
───────────────────────────────────────────────────
R: En configurant 3 variables d'environnement depuis Supabase
   1. NEXT_PUBLIC_SUPABASE_URL
   2. NEXT_PUBLIC_SUPABASE_ANON_KEY
   3. SUPABASE_SERVICE_ROLE_KEY


Q2: Où je dois coller l'URL et la KEY?
──────────────────────────────────────
R: Dans le fichier .env.local à la racine du projet

   .env.local contient:
   ├─ NEXT_PUBLIC_SUPABASE_URL=https://...
   ├─ NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJ...
   └─ SUPABASE_SERVICE_ROLE_KEY=eyJ...


ÉTAPES SIMPLES:
═══════════════

1️⃣  OBTENIR LES CLÉS
    Supabase Dashboard → Settings → API
    Copie: URL, Anon Key, Service Role Key

2️⃣  CRÉER .env.local
    À la racine du projet, crée: .env.local
    Contenu à partir de .env.local.template

3️⃣  COLLER LES CLÉS
    NEXT_PUBLIC_SUPABASE_URL=colle_url_ici
    NEXT_PUBLIC_SUPABASE_ANON_KEY=colle_clé_ici
    SUPABASE_SERVICE_ROLE_KEY=colle_service_key_ici

4️⃣  CRÉER LES TABLES
    Ouvre DATABASE_SCHEMA.sql
    Va dans Supabase SQL Editor
    Copie-colle le script et clique Run

5️⃣  REDÉMARRER L'APP
    npm run dev

6️⃣  TESTER
    http://localhost:3000/login
    Email: admin@sttis.local
    Password: Admin@123456
