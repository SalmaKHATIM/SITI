# STTIS - Guide de Démarrage Rapide

Bienvenue! Voici comment accéder rapidement à STTIS avec les identifiants de test.

## 🚀 Commencer en 3 Étapes

### Étape 1: Accédez à la Page de Démonstration
Visitez: **`http://localhost:3000/demo`**

Ou depuis la page d'accueil, cliquez sur le bouton "Identifiants de Test"

### Étape 2: Copiez les Identifiants
Vous verrez 3 comptes de test avec des boutons de copie:

```
📧 Admin
   Email: admin@sttis.tea
   Password: Admin@12345

👨‍💼 Quality Manager
   Email: qa@sttis.tea
   Password: QA@12345

📦 Stock Manager
   Email: stock@sttis.tea
   Password: Stock@12345
```

### Étape 3: Connectez-vous
1. Allez à: **`http://localhost:3000/login`**
2. Collez l'email et le mot de passe
3. Cliquez sur "Se connecter"

## 🆘 Problèmes Courants

### "Email ou mot de passe incorrect"
→ Vérifiez que vous avez copié correctement (sans espaces)
→ La casse compte (minuscules/majuscules)

### "Impossible de se créer un compte"
→ Utilisez les identifiants de test fournis
→ Si vous voulez un compte personnel, utilisez un email unique

### "Les données ne s'affichent pas"
→ Videz le cache: `Ctrl+Shift+Delete`
→ Rafraîchissez la page: `F5`
→ Reconnectez-vous

   - Vérifiez les anomalies détectées

5. **Essayez le Chat IA**
