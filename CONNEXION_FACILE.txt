Problème                    Solution
────────────────────────────────────────────────────────────────────
❌ Email/password incorrect  → Copiez depuis /demo (pas d'espaces)
❌ Connexion impossible      → Videz cache (Ctrl+Shift+Del), F5
❌ Compte ne se crée pas     → Utilisez les identifiants de test
❌ Les données ne s'affichent→ Videz cache + rechargez
❌ Erreur Supabase           → Vérifiez les env vars, consultez /help

Étape 1: Récupération des identifiants (2 min)
  → Allez à http://localhost:3000/demo
  → Copiez le compte Admin

Étape 2: Connexion (1 min)
  → Allez à http://localhost:3000/login
  → Collez l'email et mot de passe
  → Cliquez "Sign in"

Étape 3: Exploration (10 min)
  → Explorez le Dashboard
  → Allez voir les Produits
  → Vérifiez les Lots et Stock
  → Regardez les Insights IA
  → Essayez le Chat IA

Étape 4: Tester d'autres rôles (2 min)
  → Déconnectez-vous
  → Reconnectez-vous avec Quality Manager ou Stock Manager
  → Observez les différences d'accès

Traçabilité des Lots (5 min)
  1. Connectez-vous en tant que Quality Manager
  2. Allez à /dashboard/batches
  3. Cliquez sur le bouton QR d'un batch
  4. Générez et téléchargez le QR code

Prédictions IA (5 min)
  1. Allez à /dashboard/insights
  2. Cliquez "Générer Prédictions"
  3. Voir les prédictions de ventes 12 mois
  4. Consultez les anomalies détectées

Chat IA (5 min)
  1. Allez à /dashboard/chat
  2. Posez une question sur les produits ou batches
  3. L'assistant IA répondra avec des recommandations

Gestion Stock (5 min)
  1. Connectez-vous en tant que Stock Manager
  2. Allez à /dashboard/stock
  3. Consultez les niveaux d'inventaire
  4. Vérifiez les alertes et seuils
