📁 FICHIERS D'AUTHENTIFICATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. /credentials.json
   ↳ Contient les 3 comptes de test avec mots de passe
   ↳ Format JSON
   ↳ À éditer pour modifier les mots de passe

2. /lib/json-auth.ts
   ↳ Logique d'authentification (30 lignes)
   ↳ Fonctions: authenticateUser(), logoutUser(), getCurrentUser()
   ↳ Sauvegarde dans localStorage

3. /lib/auth-provider.tsx
   ↳ Context React pour authentification
   ↳ Hook: useAuth() pour accéder à l'utilisateur
   ↳ Protège les routes du dashboard

4. /app/login/page.tsx
   ↳ Formulaire de connexion
   ↳ Utilise authenticateUser()


🔧 COMMENT MODIFIER UN MOT DE PASSE?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Ouvrir /credentials.json

2. Trouver le compte à modifier:
   "email": "admin@sttis.local",
   "password": "Admin@123456"

3. Changer le mot de passe:
   "password": "NouveauMotDePasse@123"

4. Sauvegarder le fichier

5. Redémarrer l'application (Ctrl+C, puis npm run dev)

6. Se connecter avec le nouveau mot de passe

⚠️ CE SYSTÈME N'EST QUE POUR LE DÉVELOPPEMENT!

✓ Bon pour:
  - Développement local
  - Tests et démos
  - Prototypage rapide

✗ Mauvais pour:
  - Production
  - Applications en ligne
  - Données sensibles

Pour la production, utilisez:
  - Supabase Auth ✓ (Recommandé)
  - Auth0
  - NextAuth.js
  - Clerk


💾 STOCKAGE DES DONNÉES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Quand vous vous connectez:
1. Les identifiants sont vérifiés dans credentials.json
2. L'utilisateur est sauvegardé dans localStorage
3. Un token est créé pour la session
4. Vous pouvez accéder à useAuth() partout

localStorage contient:
- sttis_user: JSON de l'utilisateur
- sttis_auth_token: Token de session

Q: "Email ou mot de passe invalide"
A: Vérifiez que vous avez copié exactement l'email et mot de passe

Q: Je me suis connecté mais je vois /login
A: Redémarrez l'app (Ctrl+C, npm run dev)

Q: Mes modifications de credentials.json ne fonctionnent pas
A: Redémarrez l'application

Q: Où est mon email/mot de passe après fermeture du navigateur?
A: Il est dans localStorage et persiste tant que vous ne vous déconnectez pas
